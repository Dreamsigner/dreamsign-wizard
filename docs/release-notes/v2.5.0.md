# Dreamsign Wizard 2.5.0

Le Studio IA peut conclure un diagnostic après au moins deux QCM répondus dans la séance. Le tuteur doit produire, pour chaque prérequis, un acquis observé, une limite, une confusion éventuelle et les questions qui étayent son appréciation. Le diagnostic est conservé avec la séance et consultable dans « Mon plan pédagogique ».

Une réponse du fournisseur sans structure ou sans sources valides ne remplace pas le diagnostic : la demande reste disponible pour être réessayée. Les acquis restent des observations du tuteur à examiner, sans validation automatique de maîtrise.
