# Dreamsign Wizard 2.24.0

Studio IA permet de sélectionner ensemble jusqu'à cinq fichiers TXT, Markdown ou PDF texte pour proposer des connaissances au graphe. Les textes sont lus et validés avant l'appel au fournisseur IA, avec une limite cumulée de 40 000 caractères. Si un fichier est invalide, l'import entier échoue sans appel au modèle.

Les connaissances extraites forment une seule proposition à examiner et à accepter ou rejeter. Chaque document conserve une provenance distincte dans cette proposition. La validation individuelle de chaque fichier et la reprise d'une file d'import restent à développer.
