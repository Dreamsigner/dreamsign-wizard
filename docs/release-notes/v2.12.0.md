# Dreamsign Wizard 2.12.0

Les problèmes de pratique sont présentés dans une carte dédiée, sur toute la largeur disponible de la conversation. L'énoncé, la réponse, le raisonnement facultatif, les indices et les actions de validation sont regroupés dans un ordre plus clair.

Après la tentative, le résultat, le retour du tuteur et la solution apparaissent dans la même carte. La solution reste cachée avant la réponse. La présentation a été vérifiée sur les fenêtres larges et compactes.
