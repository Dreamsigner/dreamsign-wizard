# Dreamsign Wizard 2.15.0

La pratique garde désormais une trace persistante des difficultés à reprendre. Après un exercice non résolu ou une reprise demandée, le Studio IA propose une nouvelle situation sur la même proposition du graphe, avec le mode de pratique correspondant. Le modèle ne peut pas changer silencieusement de cible, de mode ou reprendre exactement le même énoncé.

Une reprise correcte sans indice et sans nouvelle demande de reprise clôt l'obligation liée à l'exercice initial. Les anciennes tentatives sans cible vérifiable et les propositions modifiées ne sont pas utilisées comme preuve. Le panneau signale une reprise sans révéler la notion cible ni la solution. Cette sélection reste une aide pédagogique fondée sur les observations, pas une certification automatique de maîtrise.
