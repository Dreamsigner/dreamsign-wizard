# Dreamsign Wizard 2.4.0

Le Studio IA propose désormais des problèmes de pratique autonomes. Le tuteur engage une solution avant d'afficher le problème ; elle reste masquée pendant la tentative. L'apprenant peut demander des indices gradués, écrire sa réponse et expliquer son raisonnement dans un champ distinct. Le verdict révèle ensuite la solution engagée et permet de demander explicitement le problème suivant.

Les problèmes, indices, tentatives et verdicts sont conservés dans la séance Windows. Si le fournisseur renvoie un verdict invalide ou si la requête échoue, la tentative reste enregistrée pour une nouvelle demande.

Cette version n'établit pas encore une mesure automatique de maîtrise ni un choix du prochain problème fondé sur cette mesure.
