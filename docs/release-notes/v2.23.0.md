# Dreamsign Wizard 2.23.0

Dans les paramètres, le choix du modèle propre à une séance propose désormais une recherche dans le catalogue du fournisseur actif. Le modèle par défaut reste toujours accessible, même quand la recherche filtre les autres résultats.

Un catalogue API ne sert plus à sélectionner un modèle après modification de l'URL du fournisseur. Le menu limite les résultats affichés pour rester utilisable avec de longues listes.
