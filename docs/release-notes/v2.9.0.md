# Dreamsign Wizard 2.9.0

Le plan pédagogique accepté permet de vérifier ses prérequis étape par étape. Une étape dépendante reste bloquée tant que les étapes précédentes requises ne disposent pas d'une réponse examinée et explicitement validée par l'apprenant. Les réponses candidates sont limitées aux QCM corrects accompagnés d'un raisonnement et aux problèmes résolus avec un raisonnement ; la source et le résultat restent consultables.

Les validations sont conservées avec la séance et effacées si le plan change. Elles expriment une décision de l'apprenant sur une preuve visible, sans constituer une mesure automatique de maîtrise.
