# Dreamsign Wizard 2.20.0

Dans une fenêtre étroite, Studio IA garde une barre latérale d'icônes visible. Le bouton Séances ouvre un panneau qui reprend la recherche, les filtres et la création de séances ; la conversation reste accessible d'un clic. Le rail donne aussi accès au plan, aux sources et au graphe.

Le panneau de séances remplace temporairement la conversation sur les petites fenêtres. Sur les fenêtres larges, la barre latérale existante reste en place.
