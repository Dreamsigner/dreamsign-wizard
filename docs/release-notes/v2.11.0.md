# Dreamsign Wizard 2.11.0

Les questions du Studio IA occupent désormais une carte dédiée dans la conversation. Les choix, « Je ne sais pas », le curseur de confiance et le champ de raisonnement sont regroupés avant une seule action de validation. La confiance reste facultative et peut être effacée après réglage.

Sur les fenêtres compactes, la carte défile pour garder tous les choix et la validation accessibles. La solution et son explication ne sont révélées qu'après la réponse.
