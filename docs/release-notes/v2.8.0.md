# Dreamsign Wizard 2.8.0

Les QCM du Studio IA distinguent désormais une prédiction, posée avant l'explication d'un résultat, et une vérification de compréhension. L'apprenant peut demander l'un ou l'autre dans la conversation. Le type apparaît sur la question, tandis que le choix des réponses, « Je ne sais pas », le raisonnement et la confiance restent disponibles.

La réponse et son explication restent cachées avant la validation. Les QCM des séances enregistrées avec les versions précédentes sont relus comme des vérifications de compréhension.
