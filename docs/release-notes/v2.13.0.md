# Dreamsign Wizard 2.13.0

Les exercices de pratique peuvent désormais s'appuyer sur les propositions approuvées du graphe de connaissances. Le tuteur reçoit un contexte borné qui indique les notions pertinentes pour l'objectif, les tentatives déjà résolues et celles qui demandent encore du travail. Il peut ainsi privilégier une notion peu pratiquée ou difficile et choisir un type d'exercice adapté.

Une réponse du modèle qui vise une proposition absente ou modifiée est refusée. La proposition exacte utilisée est enregistrée avec l'exercice afin que les anciennes tentatives ne deviennent pas de fausses preuves de maîtrise après une modification du graphe. La pratique reste utilisable lorsque le graphe est vide.
