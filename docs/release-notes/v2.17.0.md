# Dreamsign Wizard 2.17.0

Une séance Studio IA peut être exportée en Markdown vers un fichier choisi par l'apprenant. L'export conserve l'objectif, le plan accepté et les échanges dans l'ordre, avec les questions, réponses, raisonnements, résultats et formules tels qu'ils sont visibles dans la séance.

Les solutions des questions ou problèmes encore ouverts ne sont pas exportées. La clé IA active et les chemins locaux reconnaissables sont masqués. L'enregistrement ne remplace jamais silencieusement un fichier existant ; un autre nom doit être choisi. L'annulation et les erreurs d'écriture laissent la séance intacte.
