# Dreamsign Wizard 2.7.0

Le Studio IA permet de choisir un modèle principal pour le diagnostic, le plan et la pratique, ainsi qu'un modèle secondaire pour l'extraction du graphe. Chaque tâche peut aussi recevoir son propre modèle et niveau de réflexion. Le choix fixé pour une séance garde la priorité. Les réglages sont conservés localement et le modèle effectivement choisi est utilisé pour les appels au fournisseur.

Les informations de prix, de contexte et de niveaux de réflexion pris en charge restent inconnues tant que le fournisseur ne les fournit pas de façon fiable. Un réglage associé à une autre connexion est signalé et doit être réenregistré avant usage.
