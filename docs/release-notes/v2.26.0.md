# Dreamsign Wizard 2.26.0

La conversation Studio IA propose une dictée locale Windows. L'utilisateur démarre et arrête l'enregistrement, puis le WAV est transcrit par le lanceur de `Dictee-locale` configuré dans Paramètres. La transcription est insérée dans le brouillon éditable ; elle n'est jamais envoyée automatiquement au tuteur.

Le chemin du lanceur est enregistré, mais l'audio temporaire et le résultat de transcription ne sont pas conservés dans les séances tant que l'utilisateur n'envoie pas son message. L'enregistrement est annulé lorsqu'on quitte la séance ou ferme l'application. `Dictee-locale` copie aussi toute transcription non vide dans le presse-papiers selon son propre fonctionnement.

Le projet `Dictee-locale`, Python, son runtime et son modèle restent des dépendances locales externes à l'installateur. La dictée n'est disponible que sur Windows ; les tests emploient un enregistreur et un processus simulés, sans microphone réel.
