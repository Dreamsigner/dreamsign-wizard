# Dreamsign Wizard 2.3.0

Le Studio IA propose des questions à choix sélectionnables, y compris plusieurs réponses lorsque la question le demande. L'apprenant peut choisir « Je ne sais pas », expliquer son raisonnement et indiquer sa confiance avant de valider. La correction reste masquée jusqu'à la validation ; la réponse, le raisonnement et la confiance sont conservés dans la séance. Les questions restent utilisables dans une fenêtre compacte.

Après un diagnostic, le tuteur peut proposer un plan pédagogique structuré avec les messages qui justifient ses observations et ses étapes. La proposition est enregistrée séparément du plan déjà accepté. L'apprenant peut la corriger, l'accepter ou la retirer.

Les anciennes séances restent lisibles. Ces fonctions dépendent de la qualité du modèle choisi ; si sa réponse structurée est invalide, la demande est conservée pour être réessayée.
