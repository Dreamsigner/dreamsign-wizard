# Dreamsign Wizard 2.21.0

Les réglages des modèles par tâche proposent maintenant un menu de recherche parmi les modèles découverts pour le fournisseur actif. La liste API n'est utilisée que pour l'URL à laquelle elle correspond, afin d'éviter un choix périmé après un changement de connexion.

La saisie manuelle reste possible pour les services compatibles qui ne fournissent pas de catalogue. Le menu ne prétend pas connaître les capacités, les tarifs ou les niveaux de réflexion des modèles quand le fournisseur ne les indique pas.
