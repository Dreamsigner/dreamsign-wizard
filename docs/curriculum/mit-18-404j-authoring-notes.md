## Précision des explications et contrôles manuels

Les **27 notes originales en français** comportent 120 à 138 mots. Les **112 exercices** se répartissent en 32 questions de calcul et 80 choix raisonnés ; chaque correction expose l’étape ou l’hypothèse qui justifie la réponse. Les options sont distinctes et la position correcte varie. Les XP relèvent de l’application, pas d’un barème MIT.

La relecture manuelle porte notamment sur :

- **Automates et pompage** : acceptation après consommation complète ; ε dans l’étoile ; fermeture ε dans une déterminisation générale ; toutes les décompositions admises, et non un choix défavorable particulier. Pour 0^p1^p, supprimer le facteur non vide situé dans le premier bloc casse les comptes. Pour le pompage CFL de 0^p1^p2^p, une fenêtre touchant les trois blocs aurait au moins p+2 symboles.
- **Décidabilité et réductions** : différence entre rejeter et boucler ; reconnaisseurs complémentaires entrelacés ; réduction totale dans le sens problème difficile→cible ; construction de code distincte de l’exécution de la machine codée. Les théorèmes de Rice ou de Myhill-Nerode ne sont pas présentés comme exposés par ce cours, qui ne les développe pas ici.
- **Calculs finis et problèmes globaux** : une histoire proposée peut être vérifiée localement sans décider en général s’il en existe une ; les configurations finies d’une entrée LBA ne rendent pas toutes les propriétés de son langage décidables. Le petit exemple PCP est vérifié par concaténation des deux rangées.
- **Complexité** : taille d’encodage, surcoût de simulation, sortie polynomiale des réductions ; NP-difficulté distinguée de l’appartenance à NP ; certificats courts distingués de leur recherche. Les variables auxiliaires de SAT→3SAT préservent la satisfiabilité sans prétendre à une identité syntaxique.
- **Espace, quantificateurs et jeux** : mémoire réutilisée entre branches ; ordre ∀x∃y différent de ∃y∀x ; stratégie couvrant les réponses adverses différente d’un seul chemin favorable ; Savitch appliqué à l’espace, pas au temps ; constructibilité conservée dans les hiérarchies.
- **Oracles et questions non résolues par le cours** : une preuve qui relativise ne peut contredire un oracle où les classes coïncident. Cela ne résout pas P versus NP sans oracle et ne condamne pas toutes les méthodes de preuve. Les sondages spéculatifs des séances ne sont pas convertis en théorèmes.
