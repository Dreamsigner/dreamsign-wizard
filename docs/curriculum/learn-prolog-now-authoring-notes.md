## Relecture manuelle des réponses

Les **60 réponses et leurs corrections ont été relues par déroulement manuel**. Chaque question est indépendante : variables fraîches et base exactement indiquée, sauf état initial explicitement annoncé. Le raisonnement suppose la recherche ordinaire en profondeur, buts de gauche à droite et clauses dans l’ordre textuel ; aucun tabling implicite n’est ajouté.

| Chapitre | Exemples de contrôles manuels effectués |

| 1 | `visible(lampe)` : le premier but réussit, `present(lampe)` échoue ; conjonction donc échec. Arithmétiquement, trois arguments donnent l’arité 3. |
| 2 | `f(X,g(Y))=f(g(a),g(b))` impose `X=g(a),Y=b`. La variable répétée dans `paire(X,X)` interdit deux atomes distincts ; les deux `_` restent indépendants. `r(X)` essaie `a`, l’abandonne, puis trouve `b`. |
| 3 | `atteint(a,c)` se réduit à `arc(a,b)` puis au cas direct `arc(b,c)`. La récursion placée en premier sur la même forme de but peut empêcher d’atteindre le fait de base. Trois successeurs autour de zéro représentent trois. |
| 4 | `[H|T]=[a,b,c]` donne `H=a,T=[b,c]`. `[a,[b,c]]` possède deux éléments extérieurs. `membre` produit `p`, puis `q`, puis termine ; la transformation parallèle produit trois `b`. |
| 5 | `(4+3)*2=14`, `7//2=3`, accumulateurs `0→3→7→12`. `3=1+2` échoue structurellement ; `3=:=1+2` réussit après évaluation. `is` avec une variable droite non instanciée est une erreur, pas une résolution d’équation. |
| 6 | Quatre coupures d’une liste de longueur trois, y compris les deux extrémités. L’accumulateur d’inversion évolue `[]→[a]→[b,a]→[c,b,a]`. Le suffixe `[X]` impose `X=c`. |
