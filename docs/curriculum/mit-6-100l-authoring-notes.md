## Précisions pédagogiques

- Les flottants sont comparés avec une tolérance appropriée ; le critère sur le carré est distingué de l’erreur sur la racine. L’encadrement de la dichotomie inclut les cas entre zéro et un.
- Les exemples source comprennent des variantes volontairement erronées pour le débogage. Elles ne sont pas prises comme solutions. Le contrat, la mutation, le retour et les cas limites sont explicités.
- Les diapositives anciennes conseillent de ne supposer aucun ordre des dictionnaires. La rédaction rappelle l’ordre d’insertion en Python moderne, sans le confondre avec un tri. La clé doit être hachable ; un tuple contenant une liste ne le serait pas.
- Les assertions sont expliquées dans un fonctionnement normal et leur désactivation possible en mode optimisé est signalée ; elles ne sont pas présentées comme validation externe incontournable.
- Les coûts Θ sont liés à un modèle annoncé. Les tranches/copies de listes ont un coût ; les accès de dictionnaire ne sont pas promis constants au pire cas. La présentation simplifiée de mémoire des listes dans le dernier PDF n’est pas transposée comme une description générale des objets Python.
- Le tri aléatoire n’a pas de borne finie garantie sur le nombre de mélanges. La fréquence simulée est distinguée d’une probabilité exacte. Les exercices utilisent des observations fixées pour avoir des réponses reproductibles ; aucun résultat aléatoire particulier n’est exigé.
- Les questions de graphiques évaluent données, axes et interface pyplot. Aucun affichage graphique n’a été exécuté ou déclaré inspecté. Le modèle de dépense sportive est pédagogique, sans prétention physiologique.
